# Process State Visualizer ⚙️

An interactive web-based tool designed to visualize operating system process states and transition workflows. Built to help students and developers understand CPU scheduling, process lifecycles, and state management concepts visually.

---

## 🚀 Features

- **Interactive State Transitions:** Visualize processes moving through core OS states (`New`, `Ready`, `Running`, `Waiting/Blocked`, and `Terminated`).
- **Real-Time Queues:** Track CPU execution queues and context switching dynamically.
- **Educational Workflow:** Helps clarify how OS kernel scheduling algorithms manage process states.

---

## 🛠️ Tech Stack

- **HTML5** – Application structure
- **CSS3** – Visual styling and transition animations
- **JavaScript (ES6+)** – Interactive logic and state management
